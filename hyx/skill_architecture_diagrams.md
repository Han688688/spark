## 图4: Skill依赖关系矩阵

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          Skill依赖关系矩阵                                    │
└─────────────────────────────────────────────────────────────────────────────┘

            Skill1    Skill2    Skill3    Skill4    Skill5    External
            ───────   ───────   ───────   ───────   ───────   ────────
Skill1        -        ✓         ✓         ✓         -          -
Skill2        ✓        -         ✓         -         -          -
Skill3        ✓        ✓         -         ✓         -          -
Skill4        ✓        -         ✓         -         ✓          ✓
Skill5        -        -         -         ✓         -          -
External      -        -         -         ✓         -          -

✓ = 依赖
- = 不依赖


依赖类型：
┌──────────────┬──────────────┬──────────────────────────────────────┐
│  依赖关系     │  依赖类型     │  依赖内容                            │
├──────────────┼──────────────┼──────────────────────────────────────┤
│ Skill2→Skill1│  知识依赖     │  knowledge_graph (知识图谱)          │
│ Skill3→Skill1│  知识依赖     │  knowledge_graph (知识图谱)          │
│ Skill3→Skill2│  数据依赖     │  valid_interactions (交互列表)       │
│ Skill4→Skill1│  知识依赖     │  knowledge_graph (知识图谱)          │
│ Skill4→Skill3│  数据依赖     │  api_mappings (API映射)              │
│ Skill4→External│ 外部依赖    │  external_examples (案例库)          │
│ Skill5→Skill4│  数据依赖     │  scenarios (场景列表)                │
└──────────────┴──────────────┴──────────────────────────────────────┘


串行执行顺序：
  Skill1 → Skill2 → Skill3 → Skill4 → Skill5
  (ExternalSkill在Skill4阶段并行调用)

并行执行优化：
  Skill1 (必须先执行)
      │
      ├─────→ Skill2 ────┐
      │                  │
      ├─────→ Skill3 ────┤ (并行)
      │                  │
      └─────→ External ──┘
                │
                ▼
              Skill4
                │
                ▼
              Skill5
```

## 总结

### 架构关键点

1. **5个核心Skill** - 知识图谱、交互识别、API匹配、场景生成、文档输出
2. **链式流水线** - Skill通过输入输出串联，数据单向流动
3. **知识图谱核心** - 所有Skill共享知识图谱，支持推理
4. **混合架构** - 内嵌核心知识 + 外部扩展知识
5. **错误回退** - 每个Skill有fallback机制，保证流水线不中断

### 输入输出核心关系

```
Skill1输出 → Skill2输入
Skill1输出 → Skill3输入
Skill2输出 → Skill3输入
Skill1输出 → Skill4输入
Skill3输出 → Skill4输入
External输出 → Skill4输入
Skill4输出 → Skill5输入
Skill5输出 → 最终文档
```
