# API覆盖检测修复说明

## 修复内容

### 问题1：覆盖率计算公式错误

**原始代码**（api_coverage_plugin.py:569）：
```python
stats['overall_rate'] = len(inventory) - len(missing) / len(inventory)
```

**问题描述**：
- 运算优先级错误：先执行除法，再执行减法
- 导致覆盖率计算为负数或超大值
- 示例：192 - 183/192 = 191.05（百分比显示为19104%）

**修复后**：
```python
stats['overall_rate'] = (len(inventory) - len(missing)) / len(inventory)
```

**修复效果**：
- 正确计算：(192-183)/192 = 0.047（4.85%）
- 符合实际覆盖率情况

### 问题2：API解析不精确

**原始问题**：
- 解析出Java通用类型（String, Object, Integer等）
- 解析出JavaDoc注解标记（@Stable, @Evolving, @Deprecated）
- 解析出反射术语（Method, Field, Constructor）
- 解析出元数据标记（Stability, Schema, Signature）

**原始解析数量**：
- 总API：192个
- 包含大量错误匹配

**修复方案**：
添加黑名单过滤机制（api_coverage_plugin.py:110-132）：

```python
java_builtin_types = {
    'String', 'Object', 'Integer', 'Long', 'Double', 'Float', 'Boolean',
    'Byte', 'Short', 'Character', 'Void', 'Class', 'Number',
    'Throwable', 'Exception', 'RuntimeException', 'Error',
    'List', 'Map', 'Set', 'Collection', 'Iterator', 'Iterable',
    'ArrayList', 'HashMap', 'HashSet', 'LinkedList',
    'Optional', 'Stream', 'Path', 'File', 'URL', 'URI',
    'Comparable', 'Serializable', 'Runnable', 'Callable',
    'T', 'K', 'V', 'R', 'E', 'N', 'S', 'U',  # 泛型参数
    'Methods', 'Value', 'Key', 'Annotation',  # 元数据标记
    'Deprecated', 'Override', 'SuppressWarnings',  # Java注解
    'Stable', 'Evolving', 'Unstable', 'Private', 'Public', 'LimitedPrivate',  # API稳定性标注
    'DeveloperApi', 'Experimental', 'Unstable', 'Evolving',  # Spark API标注
    'Method', 'Field', 'Constructor', 'Signature', 'Schema',  # 反射/元数据术语
    'Stability', 'Type', 'Name', 'Id', 'Version',  # 通用属性名
    'TimeoutException', 'InterruptedException', 'IllegalArgumentException',  # 常见异常
    'IllegalStateException', 'UnsupportedOperationException',
}

# 过滤逻辑
if class_name in java_builtin_types or class_name in javadoc_tags:
    continue

if len(class_name) < 3:
    continue
```

**修复效果**：
- 总API：192 → 165（过滤27个）
- 缺失API：183 → 157（过滤26个）
- API类名更准确：
  - 修复前：String, Object, Integer, Stability, Method, Constructor...
  - 修复后：JoinWindows, StateStore, Headers, Topology, KafkaProducer...
